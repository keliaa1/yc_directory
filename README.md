 YC_Directory

YC_Directory is a modern web platform built with **Next.js** that allows users to upload, browse, and showcase startups and innovative projects. It focuses on simplicity, speed, and a clean UI to make discovering new ideas effortless.

---

## 🚀 Features
- ✨ Upload and showcase startups or innovation ideas  
- 🔍 Browse all submissions in a clean, searchable list  
- 🖼️ Each startup includes details such as name, description, images, and tags  
- ⚡ Built with **Next.js** for high performance and SEO  
- 🎨 Modern UI built with Tailwind CSS  
- 🔐 Optional authentication (if your app uses it)  
- 📄 Fully responsive on all devices  

---

## 🛠️ Tech Stack
- Next.js
- React 
- Tailwind CSS
- Appwrite
